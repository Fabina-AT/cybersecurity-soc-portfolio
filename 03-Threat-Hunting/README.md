# Threat Hunting

This section contains practical, hypothesis-driven threat hunts focused on proactively identifying suspicious activities that may be missed by existing security detections.

## Hunting Objectives

The following threat hunting scenarios are covered:

1. Suspicious PowerShell Execution
2. LOLBins Abuse
3. Persistence Hunting
4. Network Beaconing
5. Unusual Authentication
6. Credential Access
7. Lateral Movement
8. Mailbox Rule Abuse
9. Cloud Identity Abuse
10. DNS Tunneling & DGA
11. Data Staging & Exfiltration

## Data Sources

- Microsoft Sentinel
- Microsoft Defender for Endpoint
- Microsoft Entra ID
- Windows Security Events
- Sysmon
- Active Directory
- DNS, Firewall and Proxy Logs
- Cloud Audit Logs

## Hunting Approach

Each hunt includes:

- Hunting Hypothesis
- Data Sources
- Microsoft Sentinel KQL Query
- MITRE ATT&CK Mapping
- Investigation Steps
- False Positives
- Recommended Response Actions
- Hunting Conclusion

## Objective

The goal is to improve threat visibility, identify suspicious behavior, investigate potential threats, and strengthen SOC detection capabilities.
