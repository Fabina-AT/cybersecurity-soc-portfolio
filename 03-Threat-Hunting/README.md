# Threat Hunting

This section contains threat-hunting scenarios designed to proactively identify suspicious activity that may not have generated a security alert.

## Hunting Topics

* PowerShell activity
* Credential access
* Persistence
* Lateral movement
* Command execution
* Suspicious network connections
* Abnormal authentication
* Endpoint anomalies

## Hunting Methodology

1. Define the hypothesis
2. Identify relevant data sources
3. Query and analyze logs
4. Identify suspicious patterns
5. Investigate related activity
6. Determine findings
7. Create or improve detections

Threat-hunting activities are mapped to relevant MITRE ATT&CK techniques where applicable.
