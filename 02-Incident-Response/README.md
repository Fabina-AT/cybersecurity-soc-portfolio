# Incident Response

This section contains practical incident-response investigations and documented security incidents.

## Incident Types

* Brute-force attacks
* Suspicious authentication
* Malware activity
* Phishing
* Account compromise
* Unauthorized remote access
* Data exfiltration
* Suspicious endpoint activity

## Investigation Process

1. Alert triage
2. Evidence collection
3. Timeline analysis
4. Scope determination
5. Threat identification
6. Containment
7. Eradication
8. Recovery
9. Lessons learned

Each investigation documents the observed activity, analysis, indicators, response actions, and recommendations.
