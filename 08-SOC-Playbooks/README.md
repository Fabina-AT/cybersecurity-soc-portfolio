# SOC Playbooks

This section contains structured playbooks for common SOC alerts and security incidents.

## Playbooks

* Phishing investigation
* Brute-force attack
* Suspicious PowerShell
* Impossible travel
* Malware detection
* Ransomware investigation
* Unauthorized RDP
* Account compromise
* Data exfiltration

## Playbook Structure

Each playbook contains:

1. Alert description
2. Initial triage
3. Investigation steps
4. Evidence to collect
5. Indicators to check
6. Containment actions
7. Eradication and recovery
8. Escalation criteria
9. Documentation requirements

The playbooks are designed to provide repeatable investigation procedures for SOC analysts.
