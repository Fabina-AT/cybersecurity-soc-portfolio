# Cloud Security

This section contains cloud-security monitoring and investigation scenarios.

## Platforms

* AWS
* Microsoft Azure
* Google Cloud

## Topics

* Cloud authentication
* MFA monitoring
* IAM activity
* AWS CloudTrail
* Azure Activity Logs
* Suspicious API activity
* Access key activity
* Security-group changes
* Cloud resource changes

## Investigation

Each scenario focuses on identifying abnormal cloud activity, investigating the associated events, determining potential impact, and recommending security controls.
